Every request also carries `provider: {order: [pinned], allow_fallbacks: false, require_parameters: true, data_collection: "deny"}` (plus `quantizations: ["bf16"]` for Qwen). Sending an unsupported parameter with `require_parameters: true` returns HTTP 503 "no provider meets routing requirements" — that is why the parameter set is derived per model, and why the probe `or_haiku_temperature` checks it.

## OpenRouter

- Account-level settings to set once: training opt-out on, auto top-up **off**, an account spend ceiling. Credits cost the face value plus a 5.5% fee (minimum $0.80) and expire after a year.
- One API key per phase with a credit `limit` and a daily reset (`afandem-pilot`: 10).
- Paid models have no platform rate cap; `:free` variants are 20 requests/min and 50/day (1,000/day once $10 of credit has ever been bought).
- `usage.cost` comes back on every response (in credits); the served provider comes from `GET /api/v1/generation?id=<response id>` (`provider_name`).
- Errors can arrive inside an HTTP 200 body (`error` field) and moderation blocks as 403 with `metadata.reasons`; both are mapped by the harness, never scored as model behaviour.
- Provider pins were chosen from each model page's Performance tab (tool-call success rate) on 5 November 2026.

## Google (Gemini)

- Two Google Cloud projects: `afandem-free` (free-tier key, used only for public data) and `afandem-billed` (prepay $10, no auto-reload; the balance can go slightly negative under delayed billing). Enabling billing ends a project's free tier.
- Free-tier prompts are used by Google to improve its products; the billed tier's are not.
- Free-tier limits for `gemini-3.5-flash-lite` (third-party copy of the AI Studio table, approximate): 10 requests/min, 500/day. **Her own AI Studio rate-limit page: _to fill in_.**
- Gemini 3 models carry thought signatures on function-call parts; a follow-up request without them is HTTP 400. On the native API the full `Content` is appended unchanged; through OpenRouter they travel in `reasoning_details`, which must be echoed back. The day-1 probe decides which route v0 uses.

## Fanar (QCRI)

- From the public OpenAPI spec (`config/fanar-openapi-2026-11-05.json`): `Fanar-2.0-Tools` is the tool-calling model; OpenAI-shaped `/v1/chat/completions`; `tool_choice` `auto`/`none` only; `parallel_tool_calls: false` is refused; no `seed`; `temperature` defaults to 0; 8K-token context (HTTP 413 above it); 50 requests/min, each round trip counted.
- Access by request at api.fanar.qa. **Request sent: _date_. Terms received: _yes/no_.** If no terms arrive, the dataset card says "no restriction stated" and the request e-mail is kept.
