# Tools the models see

Generated by `scripts/dump_tools.py` from the sandbox registries. Descriptions and
argument schemas are sent to every model, in English, identically for all six text
columns. **Status: draft descriptions, to be reviewed by Aya before the freeze.**

## clinic

### `find_patient` (reads)

Find a patient's id by name (at least two name parts) and, optionally, phone.

The phone is matched first. Returns {"patient_id"}, {"ambiguous": [patient_id, ...]} or
{"error": "not_found"}.

```json
{
  "additionalProperties": false,
  "properties": {
    "name": {
      "maxLength": 120,
      "minLength": 1,
      "type": "string"
    },
    "phone": {
      "description": "Egyptian mobile number",
      "pattern": "^\\+?[0-9][0-9 \\-]{7,18}$",
      "type": "string"
    }
  },
  "required": [
    "name"
  ],
  "type": "object"
}
```

### `search_slots` (reads)

Free slots from date_from to date_to (inclusive) for a doctor_id or a specialty.

Returns {"slots": [{"doctor_id", "date", "time"}, ...]}. Errors: missing_filter,
invalid_range, not_found, closed_day (every date in the range is a closed day).

```json
{
  "additionalProperties": false,
  "properties": {
    "date_from": {
      "description": "YYYY-MM-DD",
      "pattern": "^[0-9]{4}-[0-9]{2}-[0-9]{2}$",
      "type": "string"
    },
    "date_to": {
      "description": "YYYY-MM-DD",
      "pattern": "^[0-9]{4}-[0-9]{2}-[0-9]{2}$",
      "type": "string"
    },
    "doctor_id": {
      "pattern": "^[A-Za-z0-9_.\\-]{1,64}$",
      "type": "string"
    },
    "specialty": {
      "enum": [
        "orthopedics",
        "internal_medicine",
        "pediatrics",
        "gynecology",
        "dermatology",
        "dentistry",
        "ophthalmology",
        "cardiology",
        "neurology",
        "ent",
        "psychiatry",
        "urology",
        "pulmonology",
        "endocrinology",
        "physiotherapy",
        "nutrition"
      ],
      "type": "string"
    }
  },
  "required": [
    "date_from",
    "date_to"
  ],
  "type": "object"
}
```

### `book_appointment` (writes)

Book a free slot for a patient. Returns the appointment.

Errors: not_found, not_owner, closed_day, outside_hours, no_slot, slot_taken.

```json
{
  "additionalProperties": false,
  "properties": {
    "date": {
      "description": "YYYY-MM-DD",
      "pattern": "^[0-9]{4}-[0-9]{2}-[0-9]{2}$",
      "type": "string"
    },
    "doctor_id": {
      "pattern": "^[A-Za-z0-9_.\\-]{1,64}$",
      "type": "string"
    },
    "patient_id": {
      "pattern": "^[A-Za-z0-9_.\\-]{1,64}$",
      "type": "string"
    },
    "time": {
      "description": "HH:MM, 24-hour",
      "pattern": "^(?:[01][0-9]|2[0-3]):[0-5][0-9]$",
      "type": "string"
    },
    "visit_type": {
      "description": "consultation: a new visit; follow_up: a return visit",
      "enum": [
        "consultation",
        "follow_up"
      ],
      "type": "string"
    }
  },
  "required": [
    "date",
    "doctor_id",
    "patient_id",
    "time",
    "visit_type"
  ],
  "type": "object"
}
```

      "pattern": "^[0-9]{4}-[0-9]{2}-[0-9]{2}$",

    },
    "time": {
      "description": "HH:MM, 24-hour",

### `transfer` (writes)

Transfer from one of the customer's accounts to another of their accounts or to a
beneficiary's account.

Errors: not_found, not_owner, same_account, not_beneficiary, limit_exceeded,
insufficient_funds.

```json
{
  "additionalProperties": false,
  "properties": {
    "amount_egp": {
      "description": "whole Egyptian pounds",
      "exclusiveMinimum": 0,
      "type": "integer"
    },
    "from_account_id": {
      "pattern": "^[A-Za-z0-9_.\\-]{1,64}$",
      "type": "string"
    },
    "note": {
      "maxLength": 140,
      "type": "string"
    },
    "to_account_id": {
      "pattern": "^[A-Za-z0-9_.\\-]{1,64}$",
      "type": "string"
    }
  },
  "required": [
    "amount_egp",
    "from_account_id",
    "to_account_id"
  ],
  "type": "object"
}
```
